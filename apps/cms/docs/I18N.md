# Đa ngôn ngữ nội dung trong Strapi Admin

Hệ thống dùng **Strapi i18n** với 2 locale mặc định:

| Code | Ngôn ngữ | Vai trò |
|------|----------|---------|
| `vi` | Tiếng Việt | **Mặc định** |
| `en` | English | Bản dịch |

Áp dụng cho: **Menu, Page, Article (bài viết), Product, Event, Category, Promotion, Site Setting, Attribute**.

## Cách nhập nội dung đa ngôn ngữ

### 1) Tạo bản tiếng Việt trước
1. Mở Content Manager → chọn loại nội dung (vd. **Page**, **Menu**, **Article**)
2. Góc phải trên có **locale switcher** → chọn **Vietnamese (vi)**
3. Nhập tiêu đề, slug, nội dung, SEO → **Save** / **Publish**

### 2) Thêm bản tiếng Anh
1. Vẫn mở entry vừa tạo
2. Đổi locale sang **English (en)**
3. Chọn **Fill in from another locale** (Sao chép từ locale khác) → chọn `vi` để copy nhanh
4. Sửa title / slug / nội dung / menu label sang tiếng Anh
5. **Save** / **Publish** bản `en`

### 3) Menu đa ngôn ngữ
- Field `items` (label + url) là **localized** → mỗi ngôn ngữ có nhãn và link riêng  
  Ví dụ VI: `/vi/san-pham` — EN: `/en/san-pham` hoặc `/en/products` nếu bạn đổi slug FE
- `slug` / `location` của Menu **không** localized (dùng chung để FE query `header`)

### 4) Trang & bài viết
- `title`, `slug`, `excerpt`, `content`, `seo` → localized
- Ảnh cover/hero thường **không** localized (dùng chung), trừ khi bạn muốn ảnh khác theo ngôn ngữ

## Kiểm tra nhanh API

```bash
# Bản Việt
curl "http://localhost:1337/api/articles?locale=vi"
curl "http://localhost:1337/api/pages?locale=vi&filters[slug][$eq]=gioi-thieu"

# Bản Anh
curl "http://localhost:1337/api/articles?locale=en"
curl "http://localhost:1337/api/menus?locale=en&filters[slug][$eq]=header"
```

## Frontend Astro
- Route prefix: `/vi/...`, `/en/...`
- Mọi fetch Strapi đều truyền `locale`
- Đổi ngôn ngữ trên site = đổi locale API

## Thêm locale mới (vd. Nhật)
1. Admin → Settings → Internationalization → **Add new locale**
2. Tạo bản dịch cho từng entry (Fill in from…)
3. Thêm locale vào `apps/web/src/i18n/ui.ts` và routes Astro
