# Đa ngôn ngữ — nội dung & giao diện Admin

## Hai lớp ngôn ngữ (đừng nhầm)

| Lớp | Ý nghĩa | Mặc định | Đổi ở đâu |
|-----|---------|----------|-----------|
| **Giao diện Admin** | Menu, nút, form Strapi | **Tiếng Việt (`vi`)** | Profile → *Interface language* |
| **Nội dung (i18n)** | Bản dịch bài viết / sản phẩm / menu… | **Tiếng Việt (`vi`)** | Locale switcher trong Content Manager |

## Giao diện Admin (VI / EN / JA)

Cấu hình: `apps/cms/src/admin/app.tsx`

- Locales UI: `vi`, `en`, `ja` (Strapi đã có bản dịch sẵn cho cả ba)
- Lần đầu mở Admin (chưa có lựa chọn trong trình duyệt): tự đặt **`vi`**
- Brand + nhãn content-type (Bài viết, Sản phẩm…) theo từng ngôn ngữ UI
- Đổi sau: avatar → **Profile** → **Interface language** → Save

Sau khi sửa `app.tsx`, cần rebuild Admin (`npm run develop` hoặc `npm run build` trong `apps/cms`), rồi hard-refresh trình duyệt.

Nếu vẫn thấy English: xóa `localStorage` key `strapi-admin-language` hoặc chọn lại Vietnamese trong Profile.

## Nội dung đa ngôn ngữ (i18n)

| Code | Ngôn ngữ | Vai trò |
|------|----------|---------|
| `vi` | Tiếng Việt | **Mặc định** |
| `en` | English | Bản dịch |
| `ja` | 日本語 (Japanese) | Bản dịch |

Áp dụng cho: **Menu, Page, Article (bài viết), Product, Event, Category, Promotion, Site Setting, Attribute**.

### 1) Tìm / tạo bài viết trong Admin
1. **Content Manager** (Quản lý nội dung) → **Bài viết** / *Article* (không phải Content-Type Builder)
2. Locale switcher góc phải → **Vietnamese (vi)** (nếu đang `ja` mà chưa có bản Nhật thì danh sách trống)
3. Nhập nội dung → **Save** rồi **Publish**

Admin luôn làm việc trên bản **Draft**; web chỉ lấy bản **Published**. Hai trạng thái này tách nhau.

### 2) Quan trọng: mỗi ngôn ngữ phải **Publish riêng**
- Bản `vi` Publish ≠ bản `en` / `ja` tự Publish
- Sau khi Fill in from another locale, nhớ bấm **Publish** lần nữa trên locale đó
- Nếu chưa Publish, web locale đó sẽ báo “chưa có bài viết”
- Nếu web có bài mà Admin trống: kiểm tra locale (vi/en/ja) và F5; tránh Publish khi chưa Save (có thể làm lệch draft/published)

### 3) Menu
- `items` (label + url) localized theo từng ngôn ngữ  
  Ví dụ: `/vi/san-pham`, `/en/san-pham`, `/ja/san-pham`
- `slug` / `location` không localized (FE query `header`)

## Kiểm tra API

```bash
curl "http://localhost:1337/api/articles?locale=ja"
curl "http://localhost:1337/api/menus?locale=ja&filters[slug][$eq]=header"
curl "http://localhost:1337/api/products?locale=ja"
```

## Frontend
- Routes: `/vi/...`, `/en/...`, `/ja/...`
- Switcher trên site: VI / EN / JP
